# 集雅社價格牌產生器

Windows 桌面程式，用來編輯商品價格牌、保存專案，並輸出實際尺寸的 PDF。本儲存庫包含 Python 原始碼；不需安裝 Python 的 Windows 版本放在 [Releases](https://github.com/ontaiko/jiya-price-card/releases)。

## 下載與開啟

1. 從 Releases 下載最新的 `JiYaPriceCard-Windows-x64-*.zip`。
2. 解壓縮整個 ZIP，保留 `JiYaPriceCard.exe` 與 `_internal` 資料夾的相對位置。
3. 雙擊 `JiYaPriceCard.exe`。首次開啟不需要網路或 Python。

程式在 Windows 啟動時會最大化，保留標題列與工作列。視窗標題、工作列與執行檔共用紅底白色「集」圖示。

先前的 v1.1.0 Windows ZIP 漏包 `tkinter`，開啟時會顯示 `No module named 'tkinter'`。請改下載 v1.1.1 或更新版本。

v1.3.0 的廠商清單在已有多個廠商時會於啟動時發生排序錯誤；請下載 v1.3.1 或更新版本。

v1.3.1 在切換廠商後可能解除集雅社標誌的鎖定；請下載 v1.3.2 或更新版本。

這是 64 位元 Windows 桌面版。啟動時會開啟廠商專案選擇視窗；每個廠商的價格牌自動保存於 `%APPDATA%\JiYaPriceCard\projects`。舊版 `%APPDATA%\JiYaPriceCard\autosave.jyp` 首次啟動時會複製為「舊專案」，原檔保留。可從「檔案 → 匯出專案備份」另存 `.jyp`。示範專案標示為「非現價」，不可直接當作目前售價使用。

## 目前功能

- 以廠商分類管理專案，啟動時選擇、新增、重新命名、移至已刪除區或還原；可匯入舊 `.jyp` 副本。
- 五種成品尺寸、七種內建版型。新增價格牌時選擇預設版型或空白尺寸；編輯後可另存為所有廠商共用的新版型，並管理版型名稱與已刪除區。
- 集中輸入商品資料、切換品牌 Logo／文字、上傳自訂圖片。
- 左上集雅社標誌及右下五條裝飾採各版型原稿的尺寸，並可像其他方塊一樣選取、拖移及縮放。
- 在預覽中拖移方塊或四角縮放；預覽滾輪以游標為中心縮放，中鍵拖曳平移。左右側欄可用滾輪捲動。方向鍵以 0.1 mm 微調，`Shift` 加方向鍵以 1 mm 移動。
- 「新增方塊」提供種類選單。右側可調整座標、大小、字級、粗體、顏色、文字背景色和對齊；兩個顏色欄位並排。左側「常用說明」暫時隱藏，已儲存的內容仍保留在專案中。
- 數值欄取得焦點時暫停該欄位的中文輸入法關聯，離開後還原；可用右側數字鍵盤輸入數字與小數點。輸入或貼上的全形數字與常見中文小數點也會轉為半形。其他文字欄仍可正常輸入中文。`Ctrl+Z` 復原、`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做，頂端亦有按鈕。
- 方塊的數值與色碼在按 Enter 或離開欄位時套用；勾選、下拉與選色立即套用。無效內容會顯示欄位提示且不更動價格牌。支援復原與重做。
- 方塊鎖定會保留於專案及共用版型；鎖定的標誌、裝飾、文字與自訂物件不會在切換廠商後自動解鎖，也不能拖移、縮放、修改幾何位置、調整圖層或刪除。
- 每個廠商專案自動保存；可匯入匯出自訂版型，或匯出 `.jyp` 專案備份。
- 匯出單張實際尺寸 PDF，或將跨廠商的列印清單依原順序排在 A4／A3 紙張上；不同尺寸只要放得下就會共用同一頁。清單中的已刪除廠商會標示為不可列印，還原或移除後即可輸出。

列印 PDF 時請在列印對話框選「實際大小／100%」。紙本尺寸仍需用實際印表機量測確認。

## 原始碼與建置

程式入口為 `run_app.py`，介面位於 `pricecard/gui.py`，資料及版型位於 `pricecard/core.py`，PDF 繪製位於 `pricecard/core_pdf.py`。內建版型在 `pricecard/resources/templates.json`。請閱讀[使用說明](使用說明.md)及[第三方素材與套件](第三方素材與套件.md)。

原始碼開發需要 64 位元 Python 3.11 或更新版本：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run_app.py
```

在 Windows 上建立執行檔可執行 `製作Windows執行檔.bat`。腳本會先確認 Python 能啟動 Tk 視窗，打包後檢查 `_tkinter` 與 Tcl/Tk 資料，缺少任一項就停止交付。建置產物為 `dist\JiYaPriceCard\JiYaPriceCard.exe`，使用時需要保留整個 `JiYaPriceCard` 資料夾。

## 企劃與現況

原企劃以瀏覽器版為方向；本版採 Windows 桌面介面。試算表批次匯入、跨裝置同步、手機介面與自動查價尚未實作。多型號資料目前固定為兩款，組合內容以文字輸入。原始企劃書存於 `docs/集雅社價格牌產生器App企劃.docx`，其中「尚未實作」為撰寫企劃當時的狀態。

商品規格與價格需由使用者核對。程式不會自動查證現價。
